# Mini E-commerce Website

## Project Description

Mini E-commerce is a web-based shopping application developed using PHP, MySQL, HTML, CSS, and JavaScript.

## Technologies Used

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* XAMPP

## Features

* User Registration and Login
* Product Listing
* Product Management
* Shopping Cart
* Admin Panel
* Database Connectivity

## Installation

1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Start Apache and MySQL.
4. Import the database into phpMyAdmin.
5. Open the project in your browser.
